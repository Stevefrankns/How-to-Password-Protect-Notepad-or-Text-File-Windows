How to Password Protect a Notepad or Text File in Windows

If you are looking for a "lock" button inside Windows Notepad, you won't find one. However, there are several reliable ways to encrypt and password protect a .txt file in Windows 10 and 11, ranging from built-in OS tools to dedicated encryption software.

By the Editorial Team · Updated November 2023 · 8 min read
Quick Answer

Windows Notepad does not have a native password protection feature. To lock a text file, you must either encrypt it using the Windows Encrypting File System (EFS), place the file inside a password-protected ZIP archive using 7-Zip, or use a dedicated file locking tool like Folder Lock for AES-256 encryption.

The Problem with Plain Text Files

Unlike Microsoft Word or Adobe PDF documents—which have built-in permissions and open passwords—a standard Notepad file (.txt) is just raw text data. It cannot natively store an encryption key or password prompt within its own format.

Because of this, you cannot simply "save as password-protected" directly in Notepad. Instead, you have to apply protection to the file from the outside. You can do this by altering the file properties, placing it in a secure container, or using a third-party application.

Method 1: Windows Encrypting File System (EFS)

Built-in Windows Tool

If you use Windows 10 or 11 Pro, Enterprise, or Education editions, you can use EFS to encrypt a Notepad file. Note: This method does not ask for a password when you open the file. Instead, it ties the encryption to your Windows user account. If someone else logs into the PC, they cannot read the file.

Step-by-step:

  1. Right-click the Notepad file and select Properties.
  2. In the General tab, click the Advanced button.
  3. Check the box that says Encrypt contents to secure data.
  4. Click OK, then Apply.
  5. Windows will ask if you want to encrypt just the file or the parent folder. Choose your preference and click OK.
Limitations: EFS is not available on Windows Home editions. Furthermore, if you email this file or put it on a USB drive, the encryption is stripped away—it only protects the file locally on your specific hard drive.

Method 2: Encrypt a Text File with 7-Zip

Free Open-Source Software

For most Windows users wanting a literal password prompt, placing the Notepad file into a secure archive is the most common free method. 7-Zip utilizes AES-256 encryption, which is incredibly secure.

How to password protect a zip file in Windows:

  1. Download and install 7-Zip.
  2. Right-click your Notepad text file.
  3. Select 7-Zip > Add to archive...
  4. In the Archive settings window, look for the Encryption section on the right side.
  5. Type your desired password twice.
  6. Ensure the Encryption method is set to AES-256.
  7. Click OK.

You now have a .zip or .7z file. When you try to open the text file inside, Windows will prompt you for the password. Remember to delete the original unprotected .txt file!

Method 3: Protect All .txt Files via Extension Masking

Third-Party Access Control

What if you want people to be able to read your text files, but you want to absolutely prevent anyone from modifying or deleting them? Traditional encryption locks the file entirely. Instead, you can use specialized directory-level security software (like Folder Protect) to set up "masks."

By targeting the *.txt extension, you can create a system-wide rule that blocks the operating system from executing delete or edit commands on text files, effectively making them bulletproof against accidental tampering or unauthorized changes, without requiring a password just to view the text.

Troubleshooting & Owner Recovery Notes

Losing access to a secure document is stressful. Here is how to handle common issues.

⚠️

How to open folder lock if password forgotten?

If you used a commercial tool like Folder Lock, look for the master key or license serial number sent to your email upon purchase. The software allows you to recover your account using the original registration credentials. Note: If you lose both your password and serial key, the AES-256 encryption cannot be bypassed.

🔒

7-zip not password protecting or cannot extract?

If 7-Zip opens but fails to extract, ensure you typed the password correctly (passwords are case-sensitive). If 7-Zip never asked for a password during creation, you likely left the encryption fields blank. Re-archive the file and verify the AES-256 method is selected.

❌

Cannot open an EFS file on a new computer?

If you moved an EFS-encrypted Notepad file to a new PC via USB, it will be unreadable unless you exported your EFS certificate from the old PC. You must go back to the original PC, remove the encryption, and then transfer the file.
